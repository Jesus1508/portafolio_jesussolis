# Portafolio Profesional – Jesús Solís Martínez

¡Bienvenido/a a mi portafolio! 👋  
Este proyecto es una representación visual de mi perfil profesional como **Desarrollador FullStack**, donde muestro mi experiencia, habilidades técnicas, proyectos reales y certificaciones obtenidas a lo largo de más de 7 años de trayectoria en el desarrollo de software.

---

## 🚀 Tecnologías principales

- **React** (con Vite) – Framework de frontend
- **TailwindCSS v4.1.4** – Estilizado moderno y responsivo
- **Framer Motion** – Animaciones suaves y fluidas
- **React Icons** – Íconos visuales por habilidad y secciones
- **EmailJS** – Envío de formularios sin backend
- **GitHub Pages / Netlify** – Despliegue del portafolio

---

## 📌 Secciones del portafolio

| Sección           | Descripción                                                                 |
|------------------|------------------------------------------------------------------------------|
| `Inicio`          | Presentación breve con animación de entrada                                 |
| `Sobre mí`        | Información profesional y experiencia relevante                              |
| `Habilidades`     | Tarjetas agrupadas por tecnología con íconos (Frontend, Backend, DB, etc.)  |
| `Proyectos`       | Proyectos reales con acceso a repositorio y demo                            |
| `Certificaciones` | Listado con enlace directo a mis certificados en Google Drive               |
| `CV`              | Enlace para descargar mi currículum y visitar mis redes profesionales       |
| `Contacto`        | Formulario de contacto funcional vía EmailJS                                |
